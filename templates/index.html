Privacy by design

Your resume is one of the most personal documents you own. Here is exactly what happens to it.

Only you can read your data Every analysis is stored under your own user ID. Requests are authorised with a Firebase ID token verified on the server for every single API call, and Firestore security rules independently block any client from reading another user's records.
What we store The resume text and job description you submit, plus the resulting analysis. We keep the source text so you can reopen and compare past applications. Nothing is used to train any model, and nothing is shared with employers or third parties.
Deletion is real deletion The Delete button on any analysis permanently removes that document — resume text, job description and results — from the database. It is not archived or soft-deleted.
Honest by construction RoleFit assesses how well-prepared an application is. It does not predict hiring outcomes, does not score you as a person, and will not help anyone claim experience they do not have.
